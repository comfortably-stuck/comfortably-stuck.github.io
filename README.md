# Comfortably Stuck project page

Static project page source for [Comfortably Stuck: Evaluation Pitfalls in
Bench2Drive's Closed-Loop Protocol](https://arxiv.org/abs/2610.21741).

The page source is kept in this private repository. The organization is on
the GitHub Free plan, which does not publish Pages sites from private
repositories, so Pages has not been configured.

The navigation-signal illustration is included in
`assets/navigation-pitfalls.png`.
